## Yang Dipelajari
- **Alur Git lengkap:** branch → commit → push → Pull Request → self-review →
  perbaikan → merge → hapus branch. Sudah dipraktikkan sendiri di PR #1.
- **Conventional Commits:** `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
- **Value vs reference:** angka/teks disalin **nilainya** (seperti kirim FILE);
  objek/array disalin **alamatnya** (seperti kirim LINK ke folder yang sama).
- **`obj.prop = x` mengubah ISI** → semua yang menunjuk objek itu ikut berubah.
  **`obj = {...}` mengganti ALAMAT** → objek lama tidak tersentuh.
- **`===` vs `==`:** selalu pakai `===`; `==` mengubah tipe otomatis dan hasilnya
  bisa mengejutkan (`0 == ""` itu `true`).
- **Truthy/falsy:** hanya 8 nilai yang falsy (`false`, `0`, `-0`, `0n`, `""`,
  `null`, `undefined`, `NaN`). Teks `"0"` dan `" "` itu **truthy**.
- **`typeof null === "object"`** — bug bersejarah JavaScript.
- **`undefined`** = belum diisi (JS yang isi). **`null`** = sengaja dikosongkan.
- **`NaN !== NaN`** — pakai `Number.isNaN()`, bukan `isNaN()`.
- **Jebakan `+`:** `"5" + 1` → `"51"` (menyambung teks), `"5" - 1` → `4`.
