# Exercises — Phase 08 Testing, Deployment, CI/CD & Monitoring

Folder ini adalah tempat mengerjakan latihan untuk [Phase 08](../README.md), sejalan dengan note di [`../notes/`](../notes/).

Latihan diumumkan mentor saat note-nya mulai dikerjakan. **Folder `01`–`10` kamu yang membuat** saat mulai mengerjakan note tersebut (pola sama seperti phase-01) — satu latihan = satu file dengan nama deskriptif.

Target minimal fase ini (lihat [README fase](../README.md) bagian *Latihan*):

- 5 latihan unit test — fungsi murni, dependency, error path, edge case, dan satu test rapuh yang diperbaiki.
- 3 latihan Testing Library — render + interaksi user, menunggu async, form.
- 2 latihan mocking — memalsukan network dan memakai fake timer.
- 1 latihan TDD — satu fungsi kecil red → green → refactor.
- 2 latihan e2e — alur login dan alur CRUD kritikal.
- 1 latihan CI — workflow GitHub Actions yang benar-benar memblokir merge saat test gagal.
- 1 latihan rollback — deploy versi rusak (di staging), deteksi lewat monitoring, lalu rollback.

## Aturan

1. **Tulis test untuk kode yang sudah kamu punya** dari fase sebelumnya — bukan kode baru hanya untuk dites.
2. **Sengaja buat test gagal** untuk membuktikan test benar-benar bekerja.
3. **Commit tiap latihan selesai** (mis. `test(phase-08): unit test kalkulasi total`).
4. **Minta review mentor** sebelum lanjut.
