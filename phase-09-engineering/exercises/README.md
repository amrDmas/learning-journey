# Exercises — Phase 09 Software Engineering & Codebase Mastery

Folder ini adalah tempat mengerjakan latihan untuk [Phase 09](../README.md), sejalan dengan note di [`../notes/`](../notes/).

Karena fase ini **berkelanjutan**, latihan bersifat **berulang** — ulangi pada project berbeda. Buat file latihanmu sendiri di folder ini (satu latihan = satu file dengan nama deskriptif), lalu commit.

Target minimal (lihat [README fase](../README.md) bagian *Latihan*):

- 1 latihan membaca codebase — tuliskan entry point + alur utama + modul inti dalam ≤ 30 menit.
- 3 latihan refactor aman — extract function, rename, hapus duplikasi (dengan karakterisasi test dulu).
- 1 latihan menulis karakterisasi test — kunci perilaku kode "jelek" sebelum mengubahnya.
- 2 latihan code review — komentar spesifik & beralasan.
- 1 latihan dokumentasi — README yang bisa diikuti + minimal 1 ADR.
- 1 latihan estimasi — pecah satu fitur, sebut asumsi & risiko.
- 1 latihan ownership — identifikasi 3 item utang teknis, urutkan prioritas, jelaskan alasan.

## Aturan

1. **Terapkan langsung ke project nyata milikmu** (dari fase 01–08) — bukan contoh mainan.
2. **Commit** hasil kerja (mis. `refactor(phase-09): ekstrak fungsi validasi`).
3. **Minta review mentor** — jelaskan *kenapa*, bukan cuma *apa*.
