# Exercises — Phase 06 Full-Stack: API + React + Auth + Integrasi

Folder ini adalah tempat mengerjakan latihan untuk [Phase 06](../README.md), sejalan dengan note di [`../notes/`](../notes/).

Latihan diumumkan mentor saat note-nya mulai dikerjakan. **Folder `01`–`11` kamu yang membuat** saat mulai mengerjakan note tersebut (pola sama seperti phase-01) — satu latihan = satu file dengan nama deskriptif.

Target minimal fase ini (lihat [README fase](../README.md) bagian *Latihan*):

- 4 latihan integrasi dasar — fetch list → loading/error/empty; form → mutation → invalidasi cache.
- 2 latihan auth — login + proteksi route; endpoint yang menolak request tanpa token.
- 2 latihan error handling — petakan kode status ke pesan UI; backend tanpa stack trace bocor.
- 2 latihan integrasi eksternal — API pihak ketiga dari backend + handler webhook dengan verifikasi signature.
- 2 latihan UX data — file upload dengan validasi, dan search + pagination tersinkron URL.
- 1 latihan diagnosa — bug CORS/preflight, temukan penyebab dan perbaiki.

## Aturan

1. **Coba dulu**, jangan intip kunci.
2. **Commit tiap latihan selesai** (mis. `feat(phase-06): integrasi tanstack query produk`).
3. **Minta review mentor** sebelum lanjut.
