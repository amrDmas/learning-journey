# Exercises — Phase 05 Database: SQL & Firestore

Folder ini adalah tempat mengerjakan latihan untuk [Phase 05](../README.md), sejalan dengan note di [`../notes/`](../notes/).

Latihan diumumkan mentor saat note-nya mulai dikerjakan. **Folder `01`–`09` kamu yang membuat** saat mulai mengerjakan note tersebut (pola sama seperti phase-01) — satu latihan = satu file dengan nama deskriptif, mis. `exercises/04/latihan-join-produk-pesanan.sql`.

Target minimal fase ini (lihat [README fase](../README.md) bagian *Latihan*):

- 10+ latihan SQL — dari `SELECT` sederhana sampai `JOIN` + `GROUP BY` + subquery.
- 8+ latihan Firestore — query modular SDK, pagination, satu composite index.
- 3 latihan desain — merancang skema SQL **dan** Firestore + alasan trade-off.
- 1 latihan diagnosa — diberi query lambat, temukan penyebab dan perbaiki.
