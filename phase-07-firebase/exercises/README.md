# Exercises — Phase 07 Firebase Deep Dive

Folder ini adalah tempat mengerjakan latihan untuk [Phase 07](../README.md), sejalan dengan note di [`../notes/`](../notes/).

Latihan diumumkan mentor saat note-nya mulai dikerjakan. **Folder `01`–`09` kamu yang membuat** saat mulai mengerjakan note tersebut (pola sama seperti phase-01) — satu latihan = satu file dengan nama deskriptif.

Target minimal fase ini (lihat [README fase](../README.md) bagian *Latihan*):

- 3 latihan Firestore lanjutan — transaction, batched write, pagination `startAfter`.
- 2 latihan auth — email/password + satu provider; satu alur custom claim/role.
- 3 latihan Security Rules — tolak akses tidak sah, validasi field, akses berbasis role (semua diuji dengan emulator).
- 3 latihan Cloud Functions — HTTP, Firestore trigger, scheduled; minimal satu idempoten.
- 1 latihan Storage — upload + rules + URL akses.
- 1 latihan diagnosa — diberi error dari log Firebase, temukan penyebab dan perbaiki.

## Aturan

1. **Jalankan Emulator Suite** setiap berlatih — jangan langsung ke produksi.
2. **Uji rules dengan emulator**, bukan tebakan.
3. **Commit tiap latihan selesai** (mis. `feat(phase-07): rules firestore produk`).
4. **Minta review mentor** sebelum lanjut.
